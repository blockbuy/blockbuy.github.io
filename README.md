# BlockBuy Pro
Professional static marketplace frontend built with HTML, CSS and JavaScript.

## Features
- Premium gaming marketplace UI
- Search, category, edition and price filters
- Favorites
- Listing detail pages/modals
- Seller studio
- Local profile
- Dark/light mode
- Grid/list view
- Responsive mobile layout
- Browser persistence with localStorage
- No framework or paid hosting required

## Cloudflare Pages
Cloudflare Pages supports Direct Upload: create a Pages project, choose Direct Upload / drag-and-drop, and upload this folder or its ZIP. The site will receive a `pages.dev` address.

## Important production note
This is a serious frontend foundation, but a real marketplace needs server-side authentication, a database, seller verification, moderation, payment processing, refunds/disputes, fraud controls and secure server integrations. Do not treat localStorage as a real account or transaction database.

The included catalog uses sample entries and does not claim that those servers/products are real or authorized. Replace them with products you are actually authorized to list.

Minecraft's current Usage Guidelines include conditions on monetization, gameplay advantages, cosmetics and virtual currencies. Review the current official rules and each server's rules before enabling real-money sales.
