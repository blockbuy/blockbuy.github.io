# BlockBuy — structured rebuild

This version moves beyond a single long page and adds dedicated routes:
- `index.html`: homepage with prominent quick links, featured drops and creator highlights
- `marketplace.html`: search, categories, edition filters, sorting and product details
- `categories.html`: dedicated category directory
- `creators.html`: creator directory
- `sell.html`: creator information and local listing preview
- `cart.html`: separate cart page
- `about.html`: project purpose
- `support.html`: FAQs and prototype limitations
- `styles.css`, `app.js`: shared design and behaviour

## Publish
Extract the ZIP. In your `blockbuy.github.io` GitHub repository, upload/replace all files at the repository root and commit. Do not upload the ZIP itself. After Pages redeploys, hard-refresh `https://blockbuy.github.io` with Ctrl+Shift+R.

## Honest limitations
This is a frontend prototype with sample data. It does not process real payments, create real accounts, or publish listings online. A real launch requires secure authentication, backend APIs, database, file storage, moderation, order/support systems, fraud controls and a compliant payment provider. Follow applicable Minecraft/Microsoft rules and local law.
