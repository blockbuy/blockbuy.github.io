# BlockBuy v2
Premium Minecraft marketplace frontend foundation.

Included:
- Modern responsive marketplace UI
- Java + Bedrock filtering
- Search, categories, sorting
- Product detail modal
- Favorites
- Seller discovery
- Seller Studio with local listing creation
- Dark/light theme
- Mobile layout

This build intentionally has NO real payments or transactions. A production marketplace requires secure backend authentication, database, file storage, moderation, order/dispute systems, fraud controls and a compliant payment provider. Real Minecraft-related sales must also follow applicable Minecraft/Microsoft and server/community rules.

For GitHub Pages: repository `blockbuy.github.io` under the GitHub account `blockbuy`, then Settings > Pages > Deploy from a branch > main > /(root).
