HELP CENTRE

Clear answers.
No guesswork.

This prototype uses sample content and browser-local interactions. It is not a live store.

Can I buy products for real?

No. The cart is a UI demo and does not collect payment or create orders.

Can creators publish listings?

The Creator Studio is a local preview only. Public publishing needs authentication, a backend, storage and moderation.

Does BlockBuy have user accounts?

Not yet. Real accounts require secure authentication and server-side data storage.

What about Minecraft usage rules?

Any real marketplace and listing must comply with applicable Minecraft/Microsoft usage guidelines and local law.

How could this become real?

The next phase needs a secure backend, database, authentication, listing moderation, order management and a compliant payment setup.
